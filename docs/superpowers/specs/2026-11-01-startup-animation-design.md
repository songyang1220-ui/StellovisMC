# StellovisMC 启动动画设计稿

状态：用户已选择“星光汇聚”推荐方案，开始实施。

## 目标

替换当前只显示小尺寸 ICO 的静态启动画面。沿用现有蓝紫星空、日系剪纸图标与柔和的玻璃界面，呈现清楚、顺滑的品牌入场。

## 推荐画面：星光汇聚

| 时间 | 画面 |
| --- | --- |
| 0–0.30 秒 | 深蓝星空显现，稀疏星尘向中心柔和收拢。 |
| 0.20–0.65 秒 | 约 112 像素的现有剪纸星星图标由轻微缩放和淡入出现，背后是一层蓝紫柔光。 |
| 0.40–0.85 秒 | StellovisMC 名称与 Minecraft Java Edition 字样浮现；粒子渐渐恢复平静。 |
| 0.85–1.10 秒 | 启动画面淡出，露出已准备好的首页，保留自然的星空衔接。 |

不加入音效、闪白或剧烈缩放。快速启动时整段约 1.1 秒；关闭启动动画或系统要求减少动画时直接进入首页。

## 方案比较

- 推荐：WPF 原生动画。复用已有图标和星空绘制，与主界面缩放一致，不增加视频文件或依赖。
- 可选视觉：流星揭幕。流星掠过点亮图标，再展开首页；动感更强，静谧感稍弱。
- 继续使用系统 SplashScreen 只能展示静态图片，无法满足此次需求；视频方案增加素材和播放开销，不采用。

## 接入约束

- 移除旧 ICO 启动画面，保留现有“显示启动画面”设置。
- 以实际主界面准备完成作为交接条件，不显示虚假进度或百分比。
- 使用动画时钟，不阻塞界面线程；结束或关闭窗口时释放动画回调。
- 首次使用协议和遥测选择仍由用户亲自处理，启动层不遮挡这些弹窗。
- 修改与验证完成后，更新发布目录及用户实际使用的 D:\Minecraft\我的世界\StellovisMC.exe。

## 验证

检查正常启动、关闭动画、减少动画、窗口提前关闭和重复启动；在实际窗口观察缩放、文字清晰度及进入首页时有无闪屏。
